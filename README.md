# Cropocalypse (Chaos by Design)

A browser-only, intentionally frustrating profile-picture cropper for the Chaos by Design UI challenge.

## Run it
1. Extract `Cropocalypse.zip`.
2. Open the `Cropocalypse` folder.
3. Double-click `index.html` (or right-click → Open with Chrome/Edge).
4. Upload a portrait image, reposition it by dragging, adjust zoom/rotation, click **Review crop**, confirm, then **Approve & download**.

No installation, backend, API key, or server is required. Images are processed locally in the browser.

## Included chaos mechanics
- Moving/nudging crop experience after selected actions
- Inverted zoom slider behavior
- Awkward rotation increments
- Square crop framing and alignment grid
- Confusing optional labels
- Distracting hints and status messages
- Multi-step confirmation/review flow
- Mirror preview toggle
- Small crop-box snap behavior while resizing
- Extra status meter and fake-urgent messages

## Important
The UI is deliberately annoying but the core workflow remains usable. The exported PNG is a real 512×512 square image. For judging, test it with a few portrait images beforehand and ensure your team can complete the exact test case within the event's required time.
